# 창업 나침반 테스트 버전

카카오 실제 장소 검색 + OpenStreetMap 지도 + 개업 준비 일정.

## 바로 배포
1. 이 폴더의 app.py, requirements.txt를 GitHub 저장소 최상위에 업로드합니다.
2. .streamlit/config.toml도 폴더 구조 그대로 추가하면 민트 테마가 적용됩니다.
3. https://developers.kakao.com 에서 앱 생성 → 카카오맵 사용 설정 ON → REST API 키 확인.
4. Streamlit Community Cloud에서 저장소 연결, Main file path를 app.py로 설정.
5. 앱 설정의 Secrets에 secrets.example.toml 형식으로 실제 카카오 키 입력 후 저장.
6. AI 키는 선택입니다. 없으면 검색 키워드를 직접 입력합니다.
7. 샐러드 등 키워드 입력 → 수원역 등 중심 장소 찾기 → 정확한 장소 선택 → 분석.

이 버전 지도는 카카오 지도가 아니라 OpenStreetMap입니다. 카카오 REST 장소 검색 결과를 지도에 표시합니다. 따라서 카카오 JavaScript 키나 지도 SDK 도메인 등록은 필요 없습니다. REST 키에 별도 접근 제한을 걸었다면 배포 서버에서 호출이 허용되는지 확인하세요.

## 안전과 한계
- 실제 비밀 키와 secrets.toml은 GitHub에 업로드하지 마세요.
- 공개 앱에서 서버 키를 저장하면 방문자의 검색도 해당 계정 쿼터를 사용합니다. 소수 테스트 후 공개 범위를 넓히세요.
- 첫 활성화 앱 무료 쿼터 조건을 확인하세요. 무제한 무료가 아닙니다.
- 중심 주변 9개 원형 구역을 동일 반경으로 비교합니다. 행정동 분석/전국 최적화가 아닙니다.
- AI는 검색어 생성만 합니다. 경쟁점 수는 실제 API 응답의 장소 ID 중복 제거로 계산합니다.
- 3페이지 이후에도 결과가 남거나 total_count가 pageable_count를 초과하면 검색 제한으로 표시하고 순위 제외합니다.
- 아파트/주택 키워드 결과에는 관련 업체가 섞일 수 있습니다. 세대 수·인구·교통량으로 해석하지 마세요.
- 시설 검색은 참고만 제공하며 순위는 경쟁 검색 점포 수 기준입니다. 임대료, 실제 수요, 유동인구 미반영.
- 후보끼리 검색 원이 겹칠 수 있습니다. 점포 수를 모두 합쳐 지역 총 점포 수로 쓰지 마세요.
- 체크 일정은 일반 예시이며 법적 개업 요건 안내가 아닙니다.
- 외부 장소 검색과 지도 로딩은 API 키/네트워크가 필요합니다. 실제 배포와 API 인증은 사용자의 키로 테스트해야 합니다.
- OpenStreetMap 타일 출처를 지우지 마세요. 대규모 배포 전 타일 정책 및 카카오 최신 약관을 검토하세요.

## 로컬 실행
pip install -r requirements.txt
streamlit run app.py

검사: Python 문법, 격자 좌표 9개 생성, 일정 날짜 계산 확인. 실제 API와 Streamlit 브라우저 화면은 미검증.
