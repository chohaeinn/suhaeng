# 사장님, 리뷰 왔어요 💬

민트색 테마의 음식점 리뷰 분석 Streamlit 테스트 앱. 배달의민족과 제휴·연동되지 않는 독립적인 프로젝트입니다.

## 기능
- API 키 없이 예시 리뷰로 규칙 기반 데모 체험
- PNG/JPG 캡처 여러 장에서 리뷰 추출 (실제 AI 모드)
- 원문 확인·수정, 공백을 제외한 동일 문구 중복 제거
- 감정 및 주제 분류, 칭찬 요약·운영 개선안·답글 초안
- 분석 결과 JSON 다운로드

## GitHub → Streamlit 배포
1. ZIP을 풀고 GitHub에 새 저장소를 만듭니다.
2. app.py와 requirements.txt를 저장소 최상위에 올립니다. 선택적으로 .streamlit/config.toml도 같은 폴더 구조로 올립니다.
3. Streamlit Community Cloud에서 GitHub 저장소를 연결하고 새 앱을 만듭니다.
4. 실행 파일(Main file path)을 app.py로 지정해 배포합니다.
5. 배포 후 데모 모드에서 ‘텍스트 입력 → 예시 리뷰 불러오기 → 리뷰 분석 시작하기’를 누릅니다.
6. 실제 AI를 쓰려면 사이드바에 본인 OpenAI API 키를 입력하거나, 앱 설정의 Secrets에 다음을 넣습니다.

```toml
OPENAI_API_KEY = "본인의_키"
```

API 키를 app.py나 GitHub에 넣지 마세요. .streamlit/secrets.toml.example은 설명용 예시이며 실제 비밀 키를 넣는 파일이 아닙니다. 파일명을 바꾸어 실제 키를 넣었다면 그 파일은 GitHub에 업로드하면 안 됩니다.

## 내 컴퓨터에서 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 실제 AI 사용
기본 모델은 이미지 입력과 JSON 출력을 지원하는 gpt-4.1-mini입니다. 계정에서 사용 가능한 이미지 입력·JSON 출력 지원 모델로 변경할 수 있습니다. API 키가 필요하며 사용 요금은 해당 API 계정에 별도로 청구됩니다. 무료 데모의 결과는 실제 AI가 아니라 단순 키워드 규칙입니다.

사진은 최대 8장, 장당 5MB이며 분석은 최대 50개 리뷰·총 25,000자입니다. 캡처에 개인정보가 있으면 먼저 가려 주세요. 전송 동의는 개인정보를 자동으로 지우는 기능이 아닙니다. 사진에서 이름을 제외하도록 요청하더라도 원본 사진 자체는 API로 전송됩니다.

## 테스트 순서
1. 데모에서 예시를 불러와 긍정·중립·부정 수와 답글을 확인합니다.
2. 리뷰를 바꾸면 기존 결과가 숨겨지는지 확인합니다.
3. AI 모드에서 개인정보 없는 리뷰 캡처 1장을 올리고 추출된 내용을 실제 사진과 비교합니다.
4. 원문을 수정한 뒤 분석하고 답글이 없는 사실이나 환불 약속을 만들지 않았는지 확인합니다.

## 범위와 한계
- 자동 수집·배달앱 로그인·답글 자동 게시·날짜별 추이·영구 저장은 없습니다.
- 문구가 같은 서로 다른 리뷰도 중복으로 합쳐질 수 있습니다. 비슷한 문구의 중복은 놓칠 수 있습니다.
- 전체 감정은 하나로 분류하며 복합 감정은 설명으로 보완합니다. 사람이 결과를 점검해야 합니다.
- 주제는 복수 선택이므로 합계가 전체 리뷰 수보다 클 수 있습니다.
- 리뷰 작성자는 전체 고객을 대표하지 않으며 만족률·매출 개선 효과를 단정할 수 없습니다.
- 데이터는 앱 내 별도 DB에 저장하지 않습니다. 세션이 종료되면 사라질 수 있습니다. 외부 AI 제공사의 데이터 보관 정책은 별도로 확인해야 합니다.
- 공개 배포 시 로그인과 호출 제한이 없습니다. 서버 Secrets에 유료 키를 넣어 누구에게나 공개하면 타인이 해당 키로 사용 요금을 발생시킬 수 있습니다. 첫 테스트는 비공개/접근 제한 환경이나 본인 키 입력 방식으로 진행하세요.
